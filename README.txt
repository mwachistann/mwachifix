MWACHI TECHNOLOGIES WEBSITE

Files:
- index.html: website structure and JavaScript
- style.css: website styling

To preview:
1. Open this folder in Visual Studio Code.
2. Install the "Live Server" extension if you do not already have it.
3. Right-click index.html and choose "Open with Live Server".

Important:
- Your HTML refers to a video at videos/tech.mp4. Create a folder named "videos"
  and put your tech.mp4 file inside it, or remove the <video> element if you do
  not have that video.
- The Google Fonts, Font Awesome icons and AOS animation library use internet
  links, so those features need an internet connection.
- The booking form opens WhatsApp; it does not store bookings on a server.

To publish with GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html and style.css to the repository's root.
3. Also upload the videos folder if you are using the background video.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish and open the URL shown on the Pages screen.
